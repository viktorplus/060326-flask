# --force-with-lease

```python
git push --force-with-lease="refs/heads/$BRANCH:$REMOTE_SHA" origin <refspec>
```

**Что это.** Принудительная перезапись ветки, но только если на сервере она всё ещё на ожидаемом коммите.

**Зачем.** `--force` затирает чужие коммиты молча. `--force-with-lease` сначала проверяет, что с момента вашей последней сверки ветку никто не трогал. Не совпало — push отклоняется, и вы узнаёте об этом до потери данных.

## Сигнатура

```python
git push --force-with-lease <remote> <refspec>
git push --force-with-lease=<ссылка>:<ожидаемый SHA> <remote> <refspec>
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `без значения` | — | — | Сравнивает с вашей локальной ссылкой `origin/<ветка>`. Требует свежего `fetch` |
| ``=<ссылка>:<SHA>`` | — | — | **Явная форма.** Вы сами говорите, какой SHA ожидаете. Надёжнее: не зависит от состояния локальных ссылок |

## Минимальный пример

```python
# Сначала узнаём текущий SHA ветки на сервере
REMOTE_SHA="$(git ls-remote --heads origin "refs/heads/$BRANCH" | awk 'NR == 1 { print $1 }')"

# Перезаписываем, но только если она всё ещё на этом SHA —
# то есть её никто не изменил между ls-remote и push.
git push --force-with-lease="refs/heads/$BRANCH:$REMOTE_SHA" \
  origin "upstream/$UPSTREAM_BRANCH:refs/heads/$BRANCH"
```

## Типичные задачи

**Безопасно перезаписать свою ветку после rebase**

```python
git fetch origin                     # обязательно: обновить представление о сервере
git push --force-with-lease origin my-branch
```

## Частые ошибки

- **Форма без значения обманчива.** Она сравнивает с ЛОКАЛЬНОЙ ссылкой `origin/<ветка>`. Если какой-то инструмент (или ваш собственный `fetch`) успел её обновить, проверка пройдёт и вы всё равно затрёте чужое. В скриптах поэтому используют явную форму `=<ссылка>:<SHA>`, как в этом workflow.
- **`stale info` при отказе** означает, что ветку изменили. Это не поломка — это сработавшая защита. Разберитесь, что там появилось.
- **Не заменяет `--force` полностью:** если ветки на сервере ещё нет, ожидаемый SHA не с чем сравнивать.
