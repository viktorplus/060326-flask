# git branch

```python
git branch -vv          git branch -d <ветка>
```

**Что это.** Показывает, создаёт и удаляет локальные ветки.

**Зачем.** Ветка в git — это просто указатель на коммит. Отсюда и дешевизна операций: создать ветку значит записать один SHA в файл.

## Сигнатура

```python
git branch                  # список
git branch -vv              # + отслеживаемые ветки и отставание
git branch -a               # включая удалённые
git branch <имя> [<коммит>] # создать, не переключаясь
git branch -d <имя>         # удалить (только слитую)
git branch -D <имя>         # удалить принудительно
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| ``-vv`` | — | — | Показать SHA, отслеживаемую ветку и расхождение с ней |
| ``-a`` | — | — | Локальные и удалённые вместе |
| ``-d`` | — | — | Удалить, если ветка слита. Иначе отказ — это защита |
| ``-D`` | — | — | Удалить в любом случае |
| ``--merged` / `--no-merged`` | — | — | Отфильтровать по тому, слита ли ветка |

## Минимальный пример

```python
git branch -vv
# * lernen_final 894bfe8 [origin/lernen_final] Add a per-function reference
#   main         df12c6a [origin/main] Merge branch 'cpython-projects:main'
```

## Типичные задачи

**Создать ветку из конкретного коммита, не переключаясь**

```python
git branch snapshot-before-refactor 24061ac
```

**Восстановить случайно удалённую ветку**

```python
git reflog                      # найти SHA, на котором она была
git branch вернувшаяся 75d6f72
```

**Найти ветки, которые уже слиты и не нужны**

```python
git branch --merged main
```

## Частые ошибки

- **`-D` вместо `-d`.** `-d` отказывается удалять неслитую ветку — это защита от потери работы. `-D` её снимает. Перед `-D` стоит посмотреть `git log <ветка>`.
- **Удалённая ветка восстановима, пока не прошёл сборщик мусора.** SHA ищется в `git reflog`, восстановление — `git branch <имя> <SHA>`.
- **Удаление локальной ветки не трогает сервер.** Для сервера нужен `git push origin --delete <ветка>`.
