# git — справочник

Здесь разобраны команды, которые участвуют в
[`.github/workflows/main.yml`](../../.github/workflows/main.yml) этого репозитория,
и решается практическая задача, ради которой этот workflow написан.

**Главная статья каталога:
[как скопировать репозиторий в отдельную ветку](copy-repo-to-branch.md)** — пять способов
от одной команды до зеркала, с разбором того, что ломается в каждом.

**Идея, на которой всё держится.** Ветка в git — это просто указатель на коммит,
а `git push` принимает refspec `<источник>:<назначение>`. Значит, чтобы положить чужую
ветку в свой репозиторий под новым именем, переключаться на неё не нужно — достаточно
одной команды. Рабочий каталог при этом не меняется вообще.

```
git fetch upstream main
git push origin upstream/main:refs/heads/snapshot-2026-09-18
```

Запускаемая демонстрация: `cd info/git && bash examples.sh` — скрипт поднимает три
временных репозитория в каталоге для временных файлов и показывает всё вышеперечисленное
на настоящих командах git, включая срабатывание защиты `--force-with-lease`.
