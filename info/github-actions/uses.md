# uses

```python
uses: actions/checkout@v5
```

**Что это.** Подключает готовое действие — чужой переиспользуемый шаг из Marketplace или из репозитория.

**Зачем.** Клонировать репозиторий, поставить Python, закэшировать зависимости — это решённые задачи. Писать их скриптом заново значит повторять чужие ошибки.

## Сигнатура

```python
uses: <владелец>/<репозиторий>@<версия>
uses: ./.github/actions/<своё>       # локальное действие
uses: docker://<образ>
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| ``@v5`` | — | — | Плавающий тег мажорной версии: получает исправления, но не ломающие изменения |
| ``@<полный SHA>`` | — | — | Жёсткая фиксация. Самый безопасный вариант для чужого кода |
| ``@main`` | — | — | Всегда свежий код действия. **Опасно**: автор может сломать вас в любой момент |

## Минимальный пример

```python
- uses: actions/checkout@v5          # клонировать репозиторий
- uses: actions/setup-python@v5      # поставить Python
  with:
    python-version: '3.13'
- uses: actions/cache@v4             # кэш зависимостей
```

## Частые ошибки

- **`@main` или `@master` у чужого действия.** Вы выполняете произвольный код, который автор может изменить в любой момент. Как минимум мажорный тег, а для чувствительных workflow — полный SHA.
- **Забыть версию вовсе** — `uses: actions/checkout` не соберётся.
- **Действие, требующее прав, без нужных `permissions`** упадёт с 403.

## Где в репозитории

- `.github/workflows/main.yml:46` — `uses: actions/checkout@v5`
- `.github/workflows/main.yml:47` — `with:`
