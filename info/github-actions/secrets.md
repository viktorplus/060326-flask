# secrets

```python
${{ secrets.MY_TOKEN }}
```

**Что это.** Зашифрованные значения, которые хранит GitHub и подставляет в workflow.

**Зачем.** Токены и пароли нельзя держать в репозитории. Секреты задаются в настройках (Settings → Secrets and variables → Actions) и в логах маскируются звёздочками.

## Сигнатура

```python
${{ secrets.<ИМЯ> }}
${{ secrets.GITHUB_TOKEN }}     # выдаётся автоматически
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| ``GITHUB_TOKEN`` | — | — | Создаётся автоматически для каждого запуска, права задаются через `permissions` |
| `Секрет репозитория` | — | — | Доступен всем workflow этого репозитория |
| `Секрет окружения` | — | — | Доступен только задачам с указанным `environment`, можно требовать ручного подтверждения |

## Минимальный пример

```python
- name: Push в другой репозиторий
  env:
    TOKEN: ${{ secrets.CROSS_REPO_TOKEN }}
  run: |
    git push "https://x-access-token:$TOKEN@github.com/owner/repo" HEAD:main
```

## Частые ошибки

- **Секреты недоступны в PR из форка.** Это защита: иначе любой желающий прислал бы PR, печатающий ваши токены.
- **Маскируется только точное совпадение.** Собрали строку из кусков или закодировали в base64 — маскировка не сработает.
- **`GITHUB_TOKEN` действует только в текущем репозитории.** Для push в другой нужен PAT.
- **Push от `GITHUB_TOKEN` не запускает другие workflow** — защита от бесконечных циклов.

## Где в репозитории

- В коде уроков не встречается: символ добавлен как популярный за пределами курса.
