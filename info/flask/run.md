# app.run

```python
if __name__ == '__main__':
    app.run(debug=True)
```

**Что это.** Поднимает встроенный отладочный сервер Werkzeug.

**Зачем.** Для разработки — самый короткий путь запустить приложение. Для боевой эксплуатации не годится: нужен полноценный WSGI-сервер (gunicorn, uwsgi, waitress).

## Сигнатура

```python
app.run(host=None, port=None, debug=None, load_dotenv=True, **options)
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `host` | str \| None | `'127.0.0.1'` | Интерфейс. `'0.0.0.0'` — принимать запросы извне машины |
| `port` | int \| None | `5000` | Порт. Занят — `OSError: [WinError 10048]` |
| `debug` | bool \| None | `None` | `True` включает автоперезагрузку при правке кода и подробную страницу ошибки с интерактивной консолью |
| `use_reloader` | bool | = `debug` | Перезапускать процесс при изменении файлов |
| `threaded` | bool | `True` | Обрабатывать запросы в отдельных потоках |

## Минимальный пример

```python
if __name__ == '__main__':
    # Защита __main__ обязательна: без неё сервер поднимется и при импорте модуля.
    app.run(debug=True)
```

## Типичные задачи

**Другой порт, если 5000 занят**

```python
app.run(port=5001, debug=True)
```

**Запуск без правки кода — через команду flask**

```python
# из каталога проекта
python -m flask --app app run --debug --port 5001
```

## Частые ошибки

- **`debug=True` поднимает ДВА процесса.** Перезагрузчик запускает дочерний процесс, поэтому «убить сервер по одному PID» не получится — порт останется занят вторым. На это наступали при проверке этого репозитория.
- **`debug=True` в боевой среде — дыра в безопасности.** Страница ошибки даёт интерактивную консоль Python прямо в браузере.
- **Порт занят.** `OSError: ... only one usage of each socket address`. Посмотреть, кто держит: `netstat -ano | findstr :5000`.
- **`app.run()` без `if __name__ == '__main__'`.** Сервер стартует при любом импорте модуля, в том числе когда приложение поднимает `flask run` или gunicorn.
