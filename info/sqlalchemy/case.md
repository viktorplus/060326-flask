# case

```python
from sqlalchemy import case
```

**Что это.** Условное выражение внутри запроса — SQL-конструкция `CASE WHEN ... THEN ... ELSE ... END`.

**Зачем.** Переносит ветвление на сторону базы. Разложить пользователей по возрастным группам можно и в Python, но тогда придётся выгрузить всю таблицу; с `case` группировка считается одним запросом.

## Сигнатура

```python
case((условие1, значение1), (условие2, значение2), ..., else_=значение)
case({ключ: значение, ...}, value=колонка, else_=...)   # форма «словарь»
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| ``*whens`` | кортежи | — | Пары `(условие, значение)`. Проверяются по порядку, срабатывает первая |
| ``else_`` | — | `NULL` | Значение, если ни одно условие не подошло |
| ``value`` | — | `None` | Колонка для формы «словарь»: сравнение на равенство |

## Минимальный пример

```python
from sqlalchemy import case, select

group = case(
    (User.age < 18, 'ребёнок'),
    (User.age < 30, 'молодой'),
    else_='взрослый',
)

rows = session.execute(select(User.name, group.label('группа')).order_by(User.name)).all()
```

Вывод:

```
[('Alice', 'взрослый'), ('Bob', 'молодой'), ('Carol', 'взрослый'),
 ('Dave', 'ребёнок'), ('Eve', 'молодой'), ('Frank', 'взрослый')]
```

## Типичные задачи

**Группировка по вычисленной категории**

```python
# Сколько человек в каждой возрастной группе — одним запросом
session.execute(select(group.label('g'), func.count(User.id)).group_by(group)).all()
# [('взрослый', 3), ('молодой', 2), ('ребёнок', 1)]
```

**Условная сумма — частый приём в отчётах**

```python
# Сколько адресов в NY и сколько в остальных городах, одной строкой
select(
    func.sum(case((Address.city == 'NY', 1), else_=0)).label('ny'),
    func.sum(case((Address.city != 'NY', 1), else_=0)).label('other'),
)
```

**Форма «словарь» — когда сравнение простое**

```python
label = case({'NY': 'Нью-Йорк', 'LA': 'Лос-Анджелес'}, value=Address.city, else_='другой')
```

**Сортировка по своему порядку**

```python
priority = case((User.name == 'Alice', 0), (User.name == 'Bob', 1), else_=99)
select(User).order_by(priority)
```

## Частые ошибки

- **Порядок условий важен.** Срабатывает ПЕРВОЕ подошедшее. Поставьте `age < 30` раньше `age < 18` — и ребёнок попадёт в «молодых».
- **Без `else_` непокрытые случаи дают `NULL`**, а не пустую строку. В группировке появится отдельная группа `None`.
- **Старый синтаксис со списком** `case([(cond, val)], ...)` в SQLAlchemy 2.0 убран — условия передаются позиционными аргументами.
- **Типы значений должны быть совместимы.** Смешивать строки и числа в разных ветках одна СУБД стерпит, другая откажется.
