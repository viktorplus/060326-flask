# .distinct()

```python
select(User).join(Address).distinct()
```

**Что это.** Убирает из результата повторяющиеся строки — SQL-конструкция `DISTINCT`.

**Зачем.** После `JOIN` по связи «один ко многим» родитель повторяется столько раз, сколько у него детей. `distinct()` сводит их к одной строке.

## Сигнатура

```python
select(...).distinct(*expressions)
```

## Минимальный пример

```python
# У Alice два адреса — без distinct она вернётся дважды
query = select(User).join(Address).distinct()
```

## Частые ошибки

- **Лечить `distinct`-ом симптом вместо причины.** Дубли после `join` — это нормальное поведение SQL; иногда правильнее не соединять, а использовать подзапрос с `in_`.
- **`DISTINCT` стоит дорого:** базе нужно отсортировать или захешировать весь результат.
- **`distinct()` действует на ВСЕ колонки выборки.** Добавили в `select` ещё одну колонку — и дубли вернулись.
