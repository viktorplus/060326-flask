# set_key

```python
from dotenv import set_key, unset_key
```

**Что это.** Записывает (`set_key`) или удаляет (`unset_key`) одну переменную прямо в файле `.env`.

**Зачем.** Нужно редко: когда конфигурацию правит программа, а не человек — установочный скрипт или CLI-утилита, сохраняющая токен после логина.

## Сигнатура

```python
set_key(dotenv_path, key_to_set, value_to_set, quote_mode='always',
        export=False, encoding='utf-8') -> tuple[bool | None, str, str]
```

## Параметры

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `dotenv_path` | str \| Path | — | Файл, который правим |
| `key_to_set` | str | — | Имя переменной |
| `value_to_set` | str | — | Значение. Всегда строка |
| `quote_mode` | str | `'always'` | `'always'` — всегда в кавычках, `'auto'` — только при необходимости, `'never'` |
| `export` | bool | `False` | Дописать префикс `export ` для совместимости с shell |

## Минимальный пример

```python
from dotenv import set_key

set_key(".env", "DRIVER", "postgresql")
```

## Частые ошибки

- **Функция перезаписывает файл и теряет комментарии и форматирование.** Файл, который читают люди, лучше править руками.
- **Секреты.** Не записывайте в `.env` то, что потом попадёт в лог или в вывод программы.
